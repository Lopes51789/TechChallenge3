## Descrição do Problema
Seu desafio será desenvolver uma solução de Engenharia de Dados e
Analytics, aplicando conceitos de Big Data e Analytics ao longo de todo o ciclo de
vida dos dados.

Embora as bases utilizadas não representem um cenário de alto volume, o
desafio simula uma arquitetura moderna de Big Data & Analytics em ambiente
Cloud, na qual os alunos devem aplicar conceitos de Data Lake, processamento
distribuído, organização em camadas, transformação de dados, catalogação,
consultas analíticas e visualização executiva.
Para isso, deverão ser utilizados obrigatoriamente:
*   Histórico das 3 últimas pesquisas disponíveis no Data Hackers;
*   Serviços da AWS através do ambiente AWS Academy Lab;
*   Draw.io para o desenho do diagrama da arquitetura da solução.
